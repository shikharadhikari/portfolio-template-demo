SHIKHAR ADHIKARI — PERSONAL PORTFOLIO

This is a static website made only with HTML, CSS, and vanilla JavaScript.
No Node.js, npm, React, build step, or package installation is required.

FILES
- index.html: all portfolio content and sections
- style.css: responsive styling and visual design
- script.js: mobile navigation and current footer year
- assets/projects/: custom SVG project illustrations

RUN LOCALLY
1. Extract the ZIP file.
2. Open index.html in any modern browser.
   For editing, open the folder in VS Code. You can also use VS Code Live Server,
   but no extension is required to view the basic site locally.

BEFORE PUBLISHING
- Verify your contact email in index.html. The current mailto uses
  contact@shikharadhikari.com.np as a suggested address; change it if needed.
- Add your actual LinkedIn profile URL in place of https://www.linkedin.com/.
- Verify project repository URLs and descriptions.
- Update any education or experience details that need exact dates/names.

DEPLOY
Upload these static files to a GitHub repository and import it into Vercel.
No build command is needed. Set the output/root directory to the folder containing index.html.
